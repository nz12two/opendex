<Callout type="note">
**Plugins vs MCPs:** enquanto plugins estendem o próprio OpenCode adicionando hooks, ferramentas e integrações, MCPs conectam agentes a ferramentas externas de forma padronizada. Plugins modificam o comportamento do OpenCode; MCPs expandem o que os agentes podem acessar.
</Callout>

## O que são plugins?

Plugins são módulos JS/TS que estendem as funcionalidades do OpenCode. Eles podem adicionar ferramentas customizadas, reagir a eventos, fazer logging e muito mais.

## Usar um plugin

### Local

Coloque o plugin em `.opencode/plugins/` (projeto) ou `~/.config/opencode/plugins/` (global). Eles são carregados automaticamente no startup.

### npm

Via config `plugin` no `opencode.json`:

```json
{ "plugin": ["opencode-helicone-session", "opencode-wakatime", "@my-org/custom-plugin"] }
```

Plugins npm são instalados com **Bun** no startup, com cache em `~/.cache/opencode/node_modules/`.

**Load order:** global config → project config → global plugin dir → project plugin dir.

## Criar um plugin

Um plugin é um módulo que exporta uma ou mais funções. Cada função recebe um contexto e retorna hooks.

```js
export const MyPlugin = async ({ project, client, $, directory, worktree }) => {
  console.log("Plugin initialized!")
  return { /* hooks */ }
}
```

O contexto inclui: `project`, `directory`, `worktree`, `client` (SDK client) e `$` (Bun shell API).

### Dependências

Se o plugin tiver dependências, coloque um `package.json` no diretório de config. O OpenCode roda `bun install` no startup.

### TypeScript

```ts
import type { Plugin } from "@opencode-ai/plugin"

export const MyPlugin: Plugin = async ({ project, client, $, directory, worktree }) => {
  return {}
}
```

## Eventos reais

- **Command**: `command.executed`
- **File**: `file.edited`, `file.watcher.updated`
- **Installation**: `installation.updated`
- **LSP**: `lsp.client.diagnostics`, `lsp.updated`
- **Message**: `message.part.removed`, `message.part.updated`, `message.removed`, `message.updated`
- **Permission**: `permission.asked`, `permission.replied`
- **Server**: `server.connected`
- **Session**: `session.created`, `session.compacted`, `session.deleted`, `session.diff`, `session.error`, `session.idle`, `session.status`, `session.updated`
- **Todo**: `todo.updated`
- **Shell**: `shell.env`
- **Tool**: `tool.execute.after`, `tool.execute.before`
- **TUI**: `tui.prompt.append`, `tui.command.execute`, `tui.toast.show`

## Exemplos reais

### Custom tool (via `tool` helper + Zod)

```ts
import { type Plugin, tool } from "@opencode-ai/plugin"

export const CustomToolsPlugin: Plugin = async (ctx) => {
  return {
    tool: {
      mytool: tool({
        description: "This is a custom tool",
        args: { foo: tool.schema.string() },
        async execute(args, context) {
          return `Hello ${args.foo}`
        }
      })
    }
  }
}
```

### Logging

```ts
client.app.log({ body: { service, level, message, extra } })
```

Níveis: `debug`, `info`, `warn`, `error`.

### Compaction hook

`experimental.session.compacting` — injeta contexto em `output.context` ou substitui o prompt com `output.prompt`.
