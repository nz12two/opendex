## Provedores

O OpenCode usa o **AI SDK** e o **Models.dev**, o que dá suporte a **75+ provedores** de modelos de linguagem, além de modelos locais. Os provedores populares vêm pré-carregados, e as credenciais são configuradas via `/connect`.

## Formato de modelo

Os modelos são referenciados no formato `provider_id/model_id`. Exemplos:

- `anthropic/claude-sonnet-4-5`
- `openai/gpt-4.1`
- `lmstudio/google/gemma-3n-e4b`
- `opencode/gpt-5.1-codex` (via OpenCode Zen)

## Selecionar modelo

No TUI, use o comando `/models` para selecionar o modelo ativo.

## Definir modelo default

No `opencode.json`:

```json
{ "model": "lmstudio/google/gemma-3n-e4b" }
```

## Configurar modelos por provider

Você pode configurar opções específicas de cada modelo no `opencode.json`:

```jsonc
{
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "options": {
            "reasoningEffort": "high",
            "textVerbosity": "low",
            "reasoningSummary": "auto",
            "include": ["reasoning.encrypted_content"]
          }
        }
      }
    },
    "anthropic": {
      "models": {
        "claude-sonnet-4-5-20250929": {
          "options": {
            "thinking": { "type": "enabled", "budgetTokens": 16000 }
          }
        }
      }
    }
  }
}
```

## Variantes

- **Built-in**: Anthropic (`high` default, `max`); OpenAI (`none`, `minimal`, `low`, `medium`, `high`, `xhigh`); Google (`low`, `high`).
- **Custom**: você pode fazer override ou adicionar variantes via `variants` (ex: `"fast": { "disabled": true }`).
- **Cycle**: use o keybind `variant_cycle` (default `ctrl+t`) para alternar entre variantes.

## Ordem de carregamento do modelo

1. Flag CLI `--model`/`-m` (formato `provider_id/model_id`)
2. Model list no config (`model` key, formato `provider/model`)
3. Último modelo usado
4. Primeiro modelo por prioridade interna

## small_model

O `small_model` é um modelo separado para tarefas leves (ex: gerar títulos de sessão). Ele faz fallback para o modelo principal se não estiver configurado.

```json
{ "small_model": "anthropic/claude-haiku-4-5" }
```

<Callout type="tip">
Para listar os modelos disponíveis de um provedor, use `opencode models [provider]` no terminal (com `--refresh` e `--verbose` para mais detalhes).
</Callout>
