<Callout type="note">
O OpenCode não expõe uma API REST pública (como `api.opencode.ai`). Em vez disso, ele oferece um **SDK oficial** (`@opencode-ai/sdk`) que se conecta a um **servidor headless** local (`opencode serve`). Este guia documenta o SDK real.
</Callout>

## O servidor headless

O OpenCode pode rodar como um servidor headless:

```bash
opencode serve
```

Por padrão, o servidor escuta na porta **4096**. Você pode configurar a porta e o hostname no `opencode.json`:

```json
{ "server": { "port": 4096, "hostname": "0.0.0.0" } }
```

Também existe o `opencode web`, que sobe uma interface web, e o `opencode attach [url]`, que anexa o TUI a um servidor backend.

## Instalar o SDK

```bash
npm install @opencode-ai/sdk
```

## Criar um client

O SDK oferece duas formas de criar um client:

### `createOpencode` — cria e conecta

```js
import { createOpencode } from "@opencode-ai/sdk"

const { client } = await createOpencode()
```

Options: `hostname` (default `127.0.0.1`), `port` (default `4096`), `signal`, `timeout` (default `5000`), `config`.

### `createOpencodeClient` — conectar a um servidor existente

```js
import { createOpencodeClient } from "@opencode-ai/sdk"

const client = createOpencodeClient({ baseUrl: "http://localhost:4096" })
```

Options: `baseUrl`, `fetch`, `parseAs`, `responseStyle` (`data`/`fields`), `throwOnError`.

## Types

Os types são gerados a partir da OpenAPI spec:

```ts
import type { Session, Message, Part } from "@opencode-ai/sdk"
```

## APIs principais

### Sessions

- `session.list()`, `session.get()`, `session.children()`
- `session.create()`, `session.delete()`, `session.update()`
- `session.init()` — cria o `AGENTS.md`
- `session.abort()`, `session.share()`, `session.unshare()`, `session.summarize()`
- `session.messages()`, `session.message()`
- `session.prompt()` — envia um prompt
- `session.command()`, `session.shell()`
- `session.revert()`, `session.unrevert()`

### Files

- `find.text()`, `find.files()`, `find.symbols()`
- `file.read()`, `file.status()`

### Config

- `config.get()`, `config.providers()`

### Project

- `project.list()`, `project.current()`

### Global / App

- `global.health()`
- `app.log()`, `app.agents()`

### Path

- `path.get()`

### TUI

- `tui.appendPrompt()`, `tui.openHelp()`, `tui.openSessions()`, `tui.openThemes()`, `tui.openModels()`
- `tui.submitPrompt()`, `tui.clearPrompt()`, `tui.executeCommand()`, `tui.showToast()`

### Auth

- `auth.set()`

### Events

- `event.subscribe()` — server-sent events

## Structured Output

Você pode pedir saída estruturada no `session.prompt` usando `format`:

```js
await client.session.prompt({
  sessionId,
  prompt: "Extract the data",
  format: { type: "json_schema", schema: { /* seu schema */ } }
})
```

- Tipos: `text` (default), `json_schema`
- Campos: `type`, `schema`, `retryCount` (default `2`)
- Erro: `StructuredOutputError`
