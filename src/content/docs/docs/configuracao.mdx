## Arquivo de configuração

O OpenCode é configurado através do arquivo `opencode.json` na raiz do seu projeto:

```json
{
  "name": "meu-projeto",
  "version": "1.0.0",
  "agents": {
    "orchestrator": {
      "model": "gpt-4",
      "temperature": 0.3
    },
    "builder": {
      "model": "gpt-4",
      "temperature": 0.2
    }
  },
  "plugins": [],
  "mcp": {
    "servers": []
  }
}
```

## Temas

<Callout type="tip">
O OpenCode suporta temas claro e escuro:

```json
{
  "theme": "dark",
  "accentColor": "#6366f1"
}
```
</Callout>

## Atalhos de teclado

| Atalho | Ação |
|--------|------|
| `Ctrl+K` | Abrir busca |
| `Ctrl+B` | Alternar sidebar |
| `Ctrl+J` | Abrir terminal |
| `Ctrl+Shift+P` | Paleta de comandos |

## Variáveis de ambiente

Configure variáveis de ambiente para APIs e serviços externos:

```bash
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
```

## Integrações

| Integração | Descrição |
|------------|-----------|
| GitHub | `github.token`, `github.repository` para integração com repositórios |
| Discord | `discord.webhook` para notificações no Discord |
