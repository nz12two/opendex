O `opencode.json` é o arquivo de configuração do **OpenCode** (o agente de IA), não um arquivo de metadados do OpenDex. Ele define modelo, agentes, plugins, MCPs, permissões e muito mais.

## Formato

Suporta **JSON** e **JSONC** (JSON com comentários). O schema oficial fica em `https://opencode.ai/config.json`.

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "model": "anthropic/claude-sonnet-4-5",
  "autoupdate": true,
  "server": { "port": 4096 }
}
```

## Campos principais

| Campo | Descrição |
|-------|-----------|
| `model` | Modelo default no formato `provider/model` |
| `small_model` | Modelo separado para tarefas leves (ex: títulos) |
| `agent` | Configuração de agentes (primary e subagents) |
| `plugin` | Lista de plugins npm |
| `mcp` | Configuração de servidores MCP |
| `permission` | Regras de permissão (`allow`/`ask`/`deny`) |
| `server` | Configuração do servidor headless (`port`, `hostname`, etc) |
| `shell` | Shell a ser usado |
| `formatter` | Configuração de formatação de código |
| `lsp` | Configuração de servidores LSP |
| `compaction` | Configuração de compactação de contexto |
| `instructions` | Arquivos de instruções adicionais |
| `disabled_providers` | Provedores desabilitados |
| `enabled_providers` | Provedores habilitados |
| `autoupdate` | Controle de atualização automática |
| `share` | Modo de compartilhamento (`manual`/`auto`/`disabled`) |
| `default_agent` | Agente primary default |
| `subagent_depth` | Profundidade máxima de subagents |
| `snapshot` | Habilita/desabilita snapshots (undo/revert) |

## Exemplos

### Modelo e autoupdate

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "anthropic/claude-sonnet-4-5",
  "small_model": "anthropic/claude-haiku-4-5",
  "autoupdate": true
}
```

### Agentes

```jsonc
{
  "agent": {
    "code-reviewer": {
      "description": "Revisa código",
      "mode": "subagent",
      "model": "anthropic/claude-sonnet-4-5",
      "permission": { "edit": "deny" }
    }
  }
}
```

### Plugins e MCP

```json
{
  "plugin": ["opencode-helicone-session"],
  "mcp": {
    "context7": { "type": "remote", "url": "https://mcp.context7.com/mcp" }
  }
}
```

### Permissões

```json
{ "permission": { "edit": "ask", "bash": "ask" } }
```

## Ordem de precedência

Os configs são **mesclados**, não substituídos. A ordem de precedência (o que vem depois sobrescreve o que vem antes): remote config → global config → `OPENCODE_CONFIG` → project config → `.opencode` directories → `OPENCODE_CONFIG_CONTENT` → managed config files → macOS managed preferences.

Para a explicação completa de cada campo, exemplos e a ordem de precedência detalhada, veja a página [Configuração](/opendex/docs/configuracao/).

## Sobre o OpenDex

O OpenDex é um catálogo que indexa o ecossistema OpenCode (plugins, agentes, MCPs, scripts) a partir de fontes reais como o npm e o GitHub. Ele não usa um `opencode.json` de metadados para descoberta — os dados vêm de coletores reais. Para publicar seu projeto no OpenDex, basta publicá-lo no npm ou no GitHub com os tópicos apropriados.
