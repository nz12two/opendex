## O que é?

O `opencode.json` é um arquivo de metadados que permite que seu plugin, agente, MCP ou skill seja **descoberto automaticamente** pelo OpenDex.

## Onde colocar

O arquivo pode estar em dois locais:

- `opencode.json` — raiz do repositório
- `.github/opendex.json` — pasta oculta do GitHub

## Formato

```json
{
  "type": "agent",
  "name": "Research Agent",
  "version": "1.2.0",
  "description": "Agente de pesquisa que busca informações na web.",
  "author": {
    "name": "Seu Nome",
    "email": "seu@email.com"
  },
  "license": "MIT",
  "category": "research",
  "tags": ["agent", "planner", "web", "search"],
  "compatibility": {
    "opencode": ">=1.3.0",
    "os": ["windows", "macos", "linux"]
  },
  "source": {
    "github": "https://github.com/seu-user/research-agent"
  }
}
```

## Campos obrigatórios

| Campo | Descrição |
|-------|-----------|
| `type` | agent, plugin, mcp, skill, template, tool, theme |
| `name` | Nome do ativo |
| `version` | Versão semântica |
| `description` | Descrição curta (máx 280 caracteres) |
| `author` | Nome do autor |
| `category` | Categoria principal |
| `tags` | Array de tags |
| `source.github` | URL do repositório GitHub |

## Score de Relevância

O OpenDex calcula automaticamente um score (0-100) para cada ativo:

- ⭐ **Stars** (0-30): Quantas estrelas no GitHub
- 📅 **Recência** (0-20): Quando foi o último commit
- 📦 **Downloads** (0-20): Downloads mensais (se for npm)
- 🎯 **Match** (0-20): Qualidade do match com "opencode"
- 👥 **Comunidade** (0-10): Interação (issues, forks)

<Callout type="tip" title="Dica">
  Para maximizar seu score, mantenha o repositório ativo e marque com `topic:opencode` no GitHub!
</Callout>
