## Configurar um provedor

No terminal, rode o comando `/connect` dentro do TUI do OpenCode. Ele abre o fluxo de autenticação: selecione o provedor, vá em `opencode.ai/auth` e cole a API key.

<Callout type="tip">
Para quem está começando, o **OpenCode Zen** é recomendado — é uma lista curada de modelos testados e prontos para uso.
</Callout>

## Iniciar o OpenCode

Navegue até o diretório do seu projeto e inicie o OpenCode:

```bash
cd /path/to/project
opencode
```

Dentro do TUI, use o comando `/init` para analisar o projeto e criar um `AGENTS.md` na raiz. É recomendado commitar esse arquivo no Git.

## Uso básico

- **Perguntar sobre arquivos:** use `@` para busca fuzzy de arquivos. Ex: `How is authentication handled in @packages/functions/src/api/index.ts`
- **Plan mode:** pressione **Tab** para desabilitar mudanças e apenas sugerir.
- **Build mode:** pressione **Tab** de novo para voltar a aplicar mudanças.
- **Desfazer:** `/undo` (pode rodar múltiplas vezes). **Refazer:** `/redo`.
- **Compartilhar:** `/share` cria um link e copia para a área de transferência. Conversas **não** são compartilhadas por padrão.
- **Imagens:** arraste e solte imagens no terminal para adicioná-las ao prompt.
