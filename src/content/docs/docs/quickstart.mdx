## Configuração

<Callout type="note">
  Certifique-se de ter **Node.js 18+** instalado antes de continuar.
</Callout>

### Passo 1: Inicialize

Abra o terminal e execute:

```bash
opencode init
```

Isso criará a estrutura inicial do projeto:

```
.opencode/
├── state/
│   ├── tasks/
│   └── checkpoints/
├── config.json
└── prompts/
```

### Passo 2: Configure

Edite o arquivo `opencode.json` na raiz do seu projeto:

```json
{
  "name": "meu-projeto",
  "version": "1.0.0",
  "agent": {
    "model": "claude-sonnet-4-20260514",
    "temperature": 0.7
  }
}
```
