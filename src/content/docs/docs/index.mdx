Bem-vindo à documentação do **OpenDex** — o catálogo oficial do ecossistema OpenCode.

<Callout type="note">
O OpenCode é um agente de IA **open source** para desenvolvimento de software. Disponível como interface de terminal, app desktop ou extensão de IDE, ele se conecta a dezenas de provedores de modelos de linguagem para ajudar você a escrever, revisar e manter código.
</Callout>

## O que é o OpenDex?

OpenDex é um marketplace e guia de referência para tudo que envolve o OpenCode: scripts, agentes, plugins, servidores MCP e ferramentas de produtividade. Esta documentação reúne, em um só lugar, os fatos reais do OpenCode — comandos de instalação, schema de configuração, agentes built-in, API de plugins, MCP, CLI, SDK e muito mais.
