<Callout type="note">
MCP (Model Context Protocol) é um padrão aberto que permite que modelos de linguagem se conectem a ferramentas externas de forma segura e padronizada. Pense nele como um "USB-C para IAs" — um único protocolo que conecta LLMs a qualquer ferramenta.
</Callout>

<Callout type="caution">
**Atenção ao contexto:** MCP adiciona ferramentas externas, mas cada MCP também adiciona **tokens de contexto**. Por exemplo, o GitHub MCP pode estourar o limite de contexto. Habilite apenas os MCPs que você realmente usa.
</Callout>

## O que é MCP?

MCP (Model Context Protocol) é um protocolo que permite que modelos de linguagem acessem ferramentas e recursos externos de forma padronizada. No OpenCode, MCPs são servidores que expõem ferramentas que os agentes podem usar.

## Habilitar um MCP

No `opencode.json`, use a chave `mcp`:

```jsonc
{ "mcp": { "name-of-mcp-server": { "enabled": true } } }
```

## MCP local

Um MCP local é um processo executado na sua máquina:

```jsonc
{
  "mcp": {
    "my-local-mcp-server": {
      "type": "local",
      "command": ["npx", "-y", "my-mcp-command"],
      "enabled": true,
      "environment": { "MY_ENV_VAR": "value" }
    }
  }
}
```

Opções local: `type` (obrigatório, `"local"`), `command` (obrigatório, array), `cwd`, `environment`, `enabled`, `timeout` (default `5000`ms).

## MCP remoto

Um MCP remoto é um servidor HTTP acessível por URL:

```json
{
  "mcp": {
    "my-remote-mcp": {
      "type": "remote",
      "url": "https://my-mcp-server.com",
      "enabled": true,
      "headers": { "Authorization": "Bearer MY_API_KEY" }
    }
  }
}
```

Opções remote: `type` (obrigatório, `"remote"`), `url` (obrigatório), `enabled`, `headers`, `oauth`, `timeout` (default `5000`ms).

## OAuth

- **Automático:** o OpenCode detecta um `401`, inicia o fluxo OAuth, faz Dynamic Client Registration (RFC 7591) e armazena os tokens em `~/.local/share/opencode/mcp-auth.json`.
- **Pré-registrado:** `oauth: { clientId, clientSecret, scope }`.
- **Desabilitar:** `oauth: false`.

## Gerenciar via CLI

```bash
opencode mcp add <server>
opencode mcp list
opencode mcp ls
opencode mcp auth <server>
opencode mcp auth list
opencode mcp logout <server>
opencode mcp debug <server>
```

## Desabilitar tools de um MCP

- **Global:** `tools: { "my-mcp-foo": false }` ou glob `"my-mcp*": false`.
- **Per agent:** desabilite globalmente e habilite no agent via `tools`.
- As tools MCP são registradas com o prefixo do nome do servidor: `"mymcpservername_*": false`.

## Exemplos reais

### Sentry

```json
{ "sentry": { "type": "remote", "url": "https://mcp.sentry.dev/mcp", "oauth": {} } }
```

Depois, autentique com `opencode mcp auth sentry`.

### Context7

```json
{ "context7": { "type": "remote", "url": "https://mcp.context7.com/mcp" } }
```

Opcional: header `CONTEXT7_API_KEY`.

### Grep by Vercel

```json
{ "gh_grep": { "type": "remote", "url": "https://mcp.grep.app" } }
```

<Callout type="tip">
Para mais detalhes sobre como criar servidores MCP, consulte a documentação oficial do protocolo. No OpenCode, o foco é **configurar** MCPs prontos, não criar servidores do zero.
</Callout>
