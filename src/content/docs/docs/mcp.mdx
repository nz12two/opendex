## O que é MCP?

MCP (Model Context Protocol) é um protocolo que permite que modelos de linguagem acessem ferramentas e recursos externos de forma padronizada. No OpenCode, MCPs são servidores que expõem ferramentas que os agentes podem usar.

## Configurando um MCP Server

No `opencode.json`:

```json
{
  "mcp": {
    "servers": [
      {
        "name": "meu-servidor",
        "command": "node",
        "args": ["servidor-mcp.js"],
        "env": {
          "API_KEY": "${API_KEY}"
        }
      }
    ]
  }
}
```

## Criando um MCP Server

Um servidor MCP minimalista em Node.js:

```javascript
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';

const server = new Server({
  name: 'meu-servidor',
  version: '1.0.0',
}, {
  capabilities: { tools: {} },
});

server.setRequestHandler('tools/list', async () => ({
  tools: [{
    name: 'saudacao',
    description: 'Retorna uma saudação personalizada',
    inputSchema: {
      type: 'object',
      properties: {
        nome: { type: 'string' },
      },
    },
  }],
}));

server.setRequestHandler('tools/call', async (request) => {
  if (request.params.name === 'saudacao') {
    return {
      content: [{
        type: 'text',
        text: `Olá, ${request.params.arguments.nome}!`,
      }],
    };
  }
});

const transport = new StdioServerTransport();
await server.connect(transport);
```
