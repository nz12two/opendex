## Pré-requisitos

<Callout type="tip">
Antes de instalar o OpenCode, certifique-se de ter:

- Um **terminal moderno**: WezTerm (cross-platform), Alacritty (cross-platform), Ghostty (Linux/macOS) ou Kitty (Linux/macOS)
- As **API keys** dos provedores LLM que você quiser usar
</Callout>

## Instalação

<Steps>
<li>

### Script de instalação (mais fácil)

```bash
curl -fsSL https://opencode.ai/install | bash
```

</li>
<li>

### Node.js (npm, bun, pnpm, yarn)

```bash
npm install -g opencode-ai
```

```bash
bun install -g opencode-ai
```

```bash
pnpm install -g opencode-ai
```

```bash
yarn global add opencode-ai
```

</li>
<li>

### Homebrew (macOS/Linux)

```bash
brew install anomalyco/tap/opencode
```

</li>
<li>

### Arch Linux

```bash
sudo pacman -S opencode   # Stable
paru -S opencode-bin      # Latest do AUR
```

</li>
<li>

### Windows

```bash
choco install opencode
scoop install opencode
npm install -g opencode-ai
mise use -g github:anomalyco/opencode
```

</li>
<li>

### Docker

```bash
docker run -it --rm ghcr.io/anomalyco/opencode
```

</li>
</Steps>

<Callout type="note">
**Windows:** é recomendado usar **WSL**. O suporte a Bun no Windows ainda está em progresso.
</Callout>

## Configurar um provedor

No TUI do OpenCode, use o comando `/connect`. Ele abre o fluxo de autenticação: selecione o provedor, vá em `opencode.ai/auth` e cole a API key.

<Callout type="tip">
Para novatos, o **OpenCode Zen** é recomendado — uma lista curada de modelos testados.
</Callout>

## Inicializar um projeto

```bash
cd /path/to/project
opencode
/init   # analisa o projeto e cria AGENTS.md na raiz
```

<Callout type="note">
É recomendado commitar o `AGENTS.md` no Git.
</Callout>

## Verificar a instalação

Confirme que tudo funcionou:

```bash
opencode --version
```
